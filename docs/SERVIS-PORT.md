# Порт модуля SERVIS на Паскаль-Монитор

`src/servis.pas` - рабочий порт PC-модуля `TSERVIS.PAS` (30708 байт, `TURK.ARJ`) на диалект Паскаль-Монитора 15.1. Компилятор PASCOMPL и библиотека 02570 не изменялись.

Текущая версия - расширенная (771 строка, этап 4): дубли, варианты, журналы, ADMIN/ADA, отдельные МАРС-области по именам, снятие лимита 64 страниц. Результаты: `docs/SERVIS-STAGE4.md`, деки `tests/servis_build4.b6` и `tests/servis_ops4.b6`. Описание ниже сохраняет историю первого порта (330 строк).

## Что реализовано

- Заголовок `PROGRAM servis(OUTPUT, INPUT, BDVECT, BDERRN, PIC)`. `INPUT` обязателен: без него компилятор 15.1 выдаёт ошибку 37.
- Инициализация `PASACD`/`PASSETAR` идемпотентна по `BDVECT[36].i + 0 = 0`.
- `SETFL`/`CLFL` открывают область МАРС `SERVIS` вместо DOS-файла `*.ARE`.
- `UstOBL`, `NovOBL`, `AErase`, `Bocct`, `Osvobo`, `Kfind`, `GetRec`, `PutRec` - каталог областей в одной области МАРС с 72-словными записями: код, длина, флаг захвата, вид, резерв, таблица свободных страниц.
- Разборчик операторов K41: `СОЗДАТЬ ОБЛАСТЬ ... ДЛИНА`, `ОЧИСТИТЬ`, `ОСВОБОДИТЬ`, `ВОССТАНОВИТЬ` и их gold-сокращения `ОБЛACTЬ`, `ПPOCTP`, `OЧИCTИ`, `OCBOБO`, `BOCCTA`. Выдаются коды ошибок K41 3, 64, 76, 78, 80, 84.

## Технические находки

1. `NEWD` принимает переменную во втором аргументе, константа даёт ошибку 11; после `PASACD` info word нужно переприсвоить.
2. `BDERRN` «липкий»: после ошибки успешные операции сохраняют старый код; сброс - `pasbdi; BDERRN := 0`.
3. `PUTD` не перезаписывает существующий ключ (ошибка 11); для обновлений нужна `MODD`.
4. Микрокоманда `FIND` возвращает ближайший ключ, поэтому проверку существования заменили на список созданных имён.
5. Латинские и кириллические омоглифы в 6-битном вводе совпадают.

## Ограничения

Каталог хранится в одной области МАРС, а не в отдельных областях по именам из gold. Таблица прав ADMIN/ADA сведена к коду области и флагу захвата. Длина области ограничена 64 страницами (`ДЛИHA 1750` из gold даст ошибку 76). Не реализованы `ОБНОВИТЬ`, `ДУБЛЬ`, `ОСВАБД`, `ЖУРНАЛ`, `УБРАТЬ`, `ИЗМЕНИТЬ` - это этап 4 плана.
