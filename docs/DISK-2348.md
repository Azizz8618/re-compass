# Карта диска 2348

Рабочий диск: `~/.besm6/2348`. Эталон: `/usr/local/share/besm6/2348`. Третья копия: `~/Yandex.Disk/simh/BESM6/MD/EC5061/2348`. Выбор файла делается переменной `BESM6_PATH`, приоритет - первый доступный каталог.

Полный md5 образа не инвариант: том используется другими проектами для PERSO-записи. Инвариант - контрольные суммы отдельных зон.

## 2348 как носитель кода МАРС

Проверено 23.11.2026: зона `630₈` (decimal 408) на 2348 байтово идентична зоне `630₈` на 2048:

```text
2048 z630 md5: d418e27188e7e0f6b58cbe52b5eb4966
2348 z630 md5: d418e27188e7e0f6b58cbe52b5eb4966
```

То есть для загрузки кода МАРС диск 2348 функционально эквивалентен диску 2048. Одновременное монтирование двух разных томов не требуется:

```text
лен 40(2348-630)^    код МАРС с того же тома
лен 41(2348)^        библиотека Pascal, зона 2570
*perso:412570
```

Проверено: все 18 внешних имён `COMTUP` разрешаются, а inline-тест `CGetBdKey` даёт `R = 3072`, `BDERRN = 0` (`tests/cgetbdkey_single.b6`). Эта схема заменяет прежнюю пару `лен 40(2048-630)^` + `лен 41(2348)^`.

## Полезные команды

```sh
besmtool list 2348
besmtool view 2348 --start=1400 --length=2 --encoding=t
besmtool search 2348 БАНДИТ
besmtool search 2348 PASBDI
besmtool dump 2348 --start=0657 --length=18 --to-file=/tmp/zone0657.bin
besmtool pass 2348
```

Кодировки `view`: `g` - ГОСТ 10859, `k` - KOI-7, `t` - Дубна, `i` - ИПМ ЦЭМИ.

## МАРС на других томах

Исторические декы используют `лен 40(2048-630)^` - код МАРС с тома 2048, зона `630₈`, и `лен 41(2148)^` - библиотека Pascal. На 2348 БАНДИТ лежит в зоне 0657, но готовой КОБЛЫ в «документальных» зонах нет: она создаётся во время прогона через `PASACD`/`PASSETAR` либо размещается на ленте 52/1234.
