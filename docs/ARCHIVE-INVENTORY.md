## Исторические материалы

Внутри `01_YELLOW_BOX_7/7_01/FILES/FIL/FIL.ARJ` (292886 байт):

- `AMER.TXT`, `JAP.TXT` - биография В. И. Филиппова: 1967-1976 система разделения времени типа JOSS для БЭСМ-6; 1976-1978 экспериментальные СУБД; 1978-1982 коммерческая СУБД «Компас» с сетевой моделью для БЭСМ-6; далее ЕС, СМ-4, PC.
- `OTCET.TXT`, `OTCET.BAK` - отчёт: первая в стране полнофункциональная СУБД с сетевой моделью КОДАСИЛ, с 1981 по 1989 реализована на БЭСМ-6, ЕС и СМ, более 100 организаций.
- `SEREBR.TXT` - «Compass developed ... for BESM-6, IBM 360/370, PDP-11 and IBM PC».
- `K72.TXT` - библиография из 87 работ, включая доклад 1983 года о Компас-БЭСМ.
