# План порта цепочки TSS и запуска 18 программ Северова

Это последний незакрытый пункт `docs/REPRODUCE-SEVEROV-ALL.md`. План описывает, как получить исполняемую цепочку `TSSDML`/`TSSDMPR`/`TSSERR`/`TSSPPR` и запустить 18 Pascal-программ из дек 12-14.

## 1. Текущее состояние (факты)

- `src/tsspr.pas` (910 строк) компилируется PASCOMPL 15.1 с **0 синтаксических диагностик** после правок v0-v11 (`docs/TSS-CHAIN.md`).
- При `*execute` получаем `ОТСУТСТВУЕТ` для 14 внешних входов: `TPCMPP1`, `TPCMPIN1`, `WPASRA`, `EXN`, `TPCMP1I`, `VPASR6`, `TPCMPL1`, `TPCMP1A`, `TPCMP1B`, `TPCMPAD1`, `ITLEN`, `SSBF5`, `TPCMP1P`, `APIC`, `APIC2`.
- Большинство процедур в `src/tsspr.pas` - заглушки: `DML`, `INKOMP`, `INBPEM`, `zamtrb`, `SSENDM`, `ERM`, `howcom`, `VarLength`, файловые процедуры. `SLANGM` не заполнен, три адреса заменены на `nil`.
- `src/comtup.pas` - рабочий порт нижнего уровня, 18 входов, собран в зоне 2570; `src/servis.pas` - рабочий порт `TSERVIS`; `src/predtgen.pas` - генератор микрокоманд; `src/genmad_full.pas` - полный MAD-интерпретатор.
- В gold-файле 345 пар `&&...&&` в 18 программах; диапазоны строк и имена эталонов перечислены в `docs/TSS-CHAIN.md`, раздел 5.2.

## 2. Принцип: переиспользовать проверенное

Не писать параллельные реализации там, где уже есть working код:

- нижний уровень - `src/comtup.pas` (18 входов, op4/op89/op90, идемпотентный `SSBF5`);
- работа с областями - `src/servis.pas` (не переписывать `TSERVIS` заново);
- генерация микрокоманд - `src/predtgen.pas`;
- разбор ЯМД в MAD-контуре - `src/genmad_full.pas` как образец токенизации;
- печать и диагностика - `WRITELN` в `OUTPUT` и `*BDERRN*`, как в `src/servis.pas`.

Новый код пишется только там, где проверенного аналога нет: `TSSDML`, `TSSDMPR`, `TSSERR`, семантическая связка `TSSPPR`/`OPBIB`, front-end для `&&...&&`.

## 3. Рабочие потоки

### W1. Линковка внешних входов COMTUP (0,5-1 день) - ВЫПОЛНЕНО

Факт: `src/tsspr-linked.pas` и `tests/tsspr-linked-ucompas.b6` получены в scratch, проверены из репозитория на свежих копиях дисков: `exit=0`, `stderr=0`, `ОТСУТСТВУЕТ=0`, эталон `tests/tsspr-linked-ucompas.expected.txt`, зонный контроль PASS. 14 входов резолвятся в адреса 254xx-260xx. Последний вызов `TPCMPAD1(tt)` заменён локальной заглушкой до уточнения слота в W4. Подробности: `docs/TSS-W1-LINKAGE.md`.

**Вход:** `src/tsspr.pas`, `src/comtup.pas`, `tests/comtup_final_build.b6`.
**Работа:** собрать `COMTUP` в отдельной деке, подключить через `*perso`; переобъявить 14 внешних сигнатур в `src/tsspr.pas` под реальные типы (по образцу `patches/ucompat.patch`); проверить, что имена≤8 символов и `ДЛИНА LIBRARY` не конфликтует.
**Выход:** дека сборки, лог без `ОТСУТСТВУЕТ`.
**Критерий:** при `*execute` нет `ОТСУТСТВУЕТ`, каталог содержит `COMTUP` и `TSSPPR`.

### W2. Замена GUI-зависимых заглушек (1-2 дня)

**Вход:** `TSSERR.PAS` (`ERROUT`, `howcom`, `fferr`), `TSSDMPR.PAS` (`PUTALF`, `PUTEOL`, `PUTINT`, `PUTPOL`), доступные `OpRoot/OpCmd/...` только в бинарном `OPCRT.TPU`.
**Работа:** сохранить сигнатуры, реализовать через `WRITELN` и `*BDERRN*`; заполнить `SLANGM` операторами (типизированные константы 15.1 не поддерживаются); восстановить формальные параметры `OPBIB`, закомментированные в строке 33 TSSPPR.
**Выход:** `src/tsserr.pas`, `src/tssdmpr.pas` или инлайненные секции в `src/tsspr.pas`.
**Критерий:** компиляция с 0 ошибок, печать диагностики содержит код ошибки и контекст.

### W3. Порт TSSDML (3-5 дней)

**Вход:** `10_09_TURK/FILES/TURK.ARJ~/TSSDML.PAS` (3142 строки), `TSSDML.INC`, `TPCX.INC`, `src/predtgen.pas`.
**Работа:** перевести на диалект 15.1 (`{` -> `(*...*)`, убрать подчёркивания, `^` -> `@`, `Addr/INC/ASSIGN/CLOSE/ERASE/HALT` заменить), инлайнить `TYPEM`, `TROCH`, `TTABCX`, `SLANGM`, `TEKOP`, `TRN`, `NAM`. Реализовать `DML(TRUE)`: разбор строки из `BUF.M` в последовательность операций над `BDVECT` и вызовов COMTUP.
**Выход:** `src/tssdml.pas`, модуль в PERSO-библиотеке.
**Критерий:** `DML(TRUE)` разбирает все 13 операций из `docs/PREDT-PORT.md` и вызывает COMTUP без `ОТСУТСТВУЕТ`.

### W4. Семантическая сверка PIC и слотов (1-2 дня)

**Вход:** `TSPIC.PAS` (`TYPPIC`, `LENOP=384`, `LENLIT=383`), `src/comtup.pas`, `src/predtgen.pas`, `TSSPPR.PRT`.
**Работа:** согласовать `PicT` порта с `TYPPIC` (поля `ipcx`, `x`, `l` с пятью вариантами, `m`); собрать таблицу соответствия для всех 296 вызовов `TPCMPP1` в TSSPPR; поразрядная сверка с `.PRT`.
**Выход:** `docs/PIC-SLOT-MAP.md`, при необходимости патч `src/comtup.pas` (сохранив 18 входов).
**Критерий:** все numerics из `TSSPPR` имеют подтверждённое соответствие; расхождения зафиксированы как `НЕ ИЗВЕСТНО`.

### W5. Front-end и 18 программ (2-4 дня)

**Вход:** 18 диапазонов строк из `docs/TSS-CHAIN.md` разд. 5.2, 345 пар `&&...&&`.
**Работа:** написать инструмент (Python) в `tools/severov/`, который:
1. вырезает текст каждой `PROGRAM` по ranges;
2. заменяет каждую пару `&& S &&` на `DMLCALL(<n>)`;
3. `DMLCALL` кладёт строку в `BUF.M`, выставляет `BUF.I/BUF.D/BUF.H`, вызывает `DML(TRUE)`;
4. оставляет Pascal-директивы `(*=L0 ...)`, `{` переводит в `(*...*)`, убирает подчёркивания;
5. генерирует деку с `*perso` для `COMTUP`, `SERVIS`, `UCOMPAS`, `TSSDML`, `TSSPPR`.
**Порядок запуска:** пилоты `SKLMON`, `AMOHED`, `ZATHED`, затем остальные 15 по таблице 5.2.
**Критерий:** 18 etalons `gold/output/deck12-*.out`, `deck13-*.out`, `deck14-*.out`; у каждого exit 0, пустой stderr, 0 `******`, нет `ОТСУТСТВУЕТ`, `EXN=0`, `BDERRN=0`, печать меню/отчёта, `КОНЕЦ ЗАДАЧИ`.

## 6. Контрольные точки

После каждого потока:

1. `make check`, `make mars-check`, `make smoke`, `bash tools/run_kompas_suite.sh`;
2. `python3 tools/check_zone_changes.py <рабочая-копия-2348>` - только разрешённые зоны (`docs/ZONE-ALLOCATION.md`);
3. md5 оригиналов `~/.besm6/*` и `/usr/local/share/besm6/*` совпадают с манифестом;
4. коммит и push в `origin` и `sourcecraft` только после зелёных проверок.

## 7. Риски

| Риск | Митигация |
|---|---|
| `PicT` порта не совпадает с `TYPPIC` | W4 до W5; таблица соответствий и `.PRT` |
| 296 вызовов `TPCMPP1` не все отображаются в МАРС | поразрядная сверка, `НЕ ИЗВЕСТНО` в `docs/GAPS.md` |
| `SLANGM` type constants не поддерживаются 15.1 | инициализация операторами (уже проверено в v5-v11) |
| GUI-зависимости `TSSERR` | замена на `WRITELN`/`BDERRN` с сохранением сигнатур |
| Потеря PERSO-библиотек при сборке 5 модулей | отдельные зоны: 2570 (COMTUP/SERVIS), 3350 (UCOMPAS), новые - из свободного диапазона `3250..3334`/`3360+`; обязателен `check_zone_changes.py` |
| Нет полного текста `TSSPPR.PRT` для сверки | использовать доступный `.PRT` из TURK.ARJ; расхождения фиксировать |

## 8. Результат

После W5 все 14 дек Северова и 18 прикладных программ имеют эталонные выводы, `docs/REPRODUCE-SEVEROV-ALL.md` закрыт, а репозиторий содержит рабочую цепочку `COMTUP + SERVIS + UCOMPAS + TSSDML + TSSPPR` с проверенной линковкой.
