# Правила работы с диском 2348

Правила собраны из смежных проектов: `re-bemsh/AGENTS.md`, `re-dispak/DISK2348.md`, `re-siprod/README.md`, `pascal-re/PERSO.md`, `arfalib/README.md`.

1. Образ 2348 только для чтения. Извлечение через `besmtool view/search/dump`, рабочие копии - в `build/` или `/tmp/.private/azizz/`. Не открывать 2348 на запись без отдельного разрешения и резервной копии.

2. Различать три копии тома: `/usr/local/share/besm6/2348` (боевая), `~/.besm6/2348` (рабочая, md5 меняется), `~/Yandex.Disk/simh/BESM6/MD/EC5061/2348` (эталон SIMH). Выбор - через `BESM6_PATH`, приоритет у первого доступного каталога.

3. Перед работой фиксировать md5 выбранного образа, после работы - снова. Инвариант - контрольные суммы зон, не md5 целого файла. Для этого проекта инвариант: md5 дампа зоны 0657 длиной 18 зон равен `1e0371b054f29adc7804d982bd8b3de6` (проверено 23.11.2026).

4. `besmtool` принимает зоны в десятичной системе, мониторные карты - в восьмеричной (`2000₈ = 1024₁₀`). Зона 2570₈ corresponds to 1400₁₀.

5. Извлекать по одной зоне. Дамп одной зоны - ровно 6144 байта (1024 слова по 6 байт). Проверять размер через `stat -c '%s %n'`. Склеенный образ из 33 зон (202752 байт) нельзя подавать `disbesm6`: лимит 32768 слов, будет `exit=139`.

6. Дизассемблировать так: `disbesm6 -a0 -e0 gold/Z0657-L18.bin > disasm/Z0657-L18.asm 2> disasm/Z0657-L18.err`. Флаг `-e` обязателен, иначе код печатается как `конд`. ANSI-коды срезать `sed -r 's/\x1B\[[0-9;]*m//g'`, числовые поля не редактировать.

7. Имена файлов: `gold/<PREFIX>-Z<зона>-L<длина>.bin`, `disasm/*.asm`, `src/*.be`, `sym/*.tab`, `verify/report.md`, `manifest.sha256`. `G` - эталон, `S` - реконструкция.

8. Побайтовая сверка обязательна для смены статуса: `cmp roundtrip.bin gold/zone.bin`, `sha256sum -c manifest.sha256`. Для исходников - `WORDS: всего=1024 совпало=1024 различий=0` и `RESULT: PASS`. Результат писать в `verify/report.md`.

9. Копирование зон между томами только по разрешению: `besmtool write 2348 --start=02300 --from-disk=2048 --from-start=01700 --length=0100`. Перед PERSO-записью - резерв `cp ~/.besm6/2348 ~/.besm6/2348.bak-<цель>-<дата>`.

10. Карты ДИСПАК: `лен 41(2348)^` - чтение, `лен 41(2348-wr)^` - запись. `*perso:402570` грузит библиотеку зоны 2570₈, `,CONT` дозаписывает, `*to perso:402570` пишет обратно. По правилам `pascal-re` карта `*STAND` включает модульный `PASCOMPL`; в проверенном прогоне `tests/mars_smoke.b6` баннер остался 15.1 и без неё, поэтому её решающее значение для этого образа не подтверждено.

11. Для поиска следов МАРС/КОМПАС использовать `make scan` и `besmtool search` с кириллическими маркерами `БАНДИТ`, `КОБЛА`, `МАРС`, а не только латиницей: код МАРС на 2348 помечен как `БАНДИТ`, поиск `MARS` его не находит.

12. В git не коммитить `*.bin`, `*.b6`, `build/`, `gold/*.bin`, `verify/*.bin`, `*.bak*`, логи и полные образы. Перед коммитом: `git status`, `git diff`, `make check`, проверка на секреты, актуальность `STATUS.md`. Коммит и push - только по явной инструкции. Неизвестное фиксировать в `GAPS.md` как `НЕ ИЗВЕСТНО`, гипотезу - как `ГИПОТЕЗА`, подтверждённое - как `ФАКТ` с путём к источнику.
