# W10: детерминированные заглушки ZATTAB

По решению пользователя подлинное содержимое наборов `SY-HAK`, `ИC-ЗAT`, `ЭT-ЗAT` не требуется. Эти area физически отсутствуют в доступном архиве (`docs/TSS-W9B.md`), поэтому поля, которые исторически читались из них, заменены детерминированными заглушками.

## Что изменено

- В `src/generated/ZATTAB.pas` добавлена функция `STUBV(K)`: значения 10, 20, 15, 8, 5, 3, 2, 1 для K=1..8.
- 23 выражения вида `W8NUM(Qbf[k])/...` заменены на `STUBV(k)` (поля `ЗAT.*`, `HAКЛ.*`, `ZATVL.*`).
- Подлинные коэффициенты из gold (`ZKCC=0.14`, `ZKЭФЗ=0.3747`, `ZKФPEЗ=0.1`, `ZKФMП=0.6584`, `ZKФHT=0.2416`) остались в `INITDATA`.
- Деки `tests/severov-apps/ZATTAB.b6` и `tests/severov-apps/branches/ZATTAB-final.b6` пересобраны из обновлённого исходника; эталоны обновлены.

## Проверка

- `ZATTAB`: 224 runtime-строки `МАD FULL ЕХ=0`, `ТАБЛИЦА ЗАТРАТ ЗА МЕСЯЦ`, `ИТОГО`, `КОНЕЦ ЗАДАЧИ`, stderr пуст.
- Полный `make test-all`: 122 деки, 112 `MATCH`, 0 `DIFF`, 122/122 `exit=0`, 122/122 пустой stderr, зонный контроль PASS.

Заглушки не выдаются за исторические данные: в исходнике есть явный комментарий `ZATTAB-STUB`.
