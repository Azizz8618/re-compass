# re-compass: восстановление СУБД «КОМПАС» для БЭСМ-6

## Архитектура восстановления

Архитектура уточнена 23.11.2026 на основе материалов архива Ильина и смежных проектов.

**Основной текст КОМПАС сохранился на Паскале.** Это PC-ветка Turbo Pascal 5/7 в кодировке CP866: `TSSDML.PAS` (язык манипулирования данными, 3142 строки), `COMFY.PAS`, `TTC.PAS`, `UCOMPIL.PAS`, `UCOMPAS.PAS`, модель данных `CMPSNO.PAS`/`UCMPSN.PAS`, структура микрокода `TSPIC.PAS`/`UNPIC.PAS`.

**Не хватает только нижнего уровня, работы с носителями.** В PC-версии это `COMTUP.PAS` (17 внешних процедур), резидентный `COMPASST.OBJ` (TSR, `INT 12h`) и файлы DOS.

**На БЭСМ-6 за нижний уровень отвечает система МАРС.** Ядро МАРС (БАНДИТ) восстановлено в машинном коде, дизассемблировано в `besm6.github.io/sources/mars/` и присутствует на рабочем диске 2348 в зоне 0657. Из Pascal к ней обращаются стандартными процедурами `NEWD`, `OPEND`, `PUTD`, `GETD`, `MODD`, `DELD` и внешними `PASACD`, `PASSETAR`, `PASBDI`, `PASBD`. МАРС сама не написана на Pascal, но работает из Pascal, и этого достаточно для сборки.

**Задача репозитория:** заменить PC-слой `COMTUP`/`COMPASST.OBJ` на вызовы МАРС, сохранив верхние Pascal-слои, и проверить результат на диске 2348.

## Слои и их состояние

| Слой | Файлы или носитель | Состояние |
|---|---|---|
| ЯОД, ЯМД, компилятор | `TSSDML.PAS`, `COMFY.PAS`, `TTC.PAS`, `UCOMPIL.PAS` | текст есть в архиве |
| Модель данных, микрокод | `CMPSNO.PAS`, `UCMPSN.PAS`, `TSPIC.PAS`, `UNPIC.PAS`, `UNIOBJ.PAS` | есть, кандидаты на перенос без изменений |
| API доступа к БД | `UCOMPAS.PAS` | есть, но зашиты PC-коды операций, нужна тонкая обёртка |
| Работа с областями | `TSERVIS.PAS` | есть, построена на `COMTUP`, требует порта |
| Нижний уровень PC | `COMTUP.PAS`, `COMPASST.OBJ`, `.ASM`-модули | подлежит замене |
| Нижний уровень БЭСМ | МАРС/БАНДИТ, зона 0657 диска 2348, `PASBDI`/`PASBD` | есть, дизассемблировано, проверено из Pascal |

## Рабочий диск

Диск 2348: `/usr/local/share/besm6/2348` и `~/.besm6/2348`. Различаются как файлы, но дамп зоны 0657 длиной 18 зон совпадает: `md5 = 1e0371b054f29adc7804d982bd8b3de6` (проверено 23.11.2026). Полный md5 образа не инвариант, инвариант - контрольные суммы зон.

Код МАРС исторически монтируется `лен 40(2048-630)^`, библиотека Pascal на 2348 - `*perso:402570` (зона `2570₈`). Готовый пример дек: `besm6.github.io/sources/mars/sorucom.b6`.

## Статус и проверки

Статус меняется только по факту, подтверждённым артефактом. Текущее состояние: `docs/STATUS.md`. Правила работы с диском 2348: `docs/RULES-2348.md`.

```sh
make help        # список целей
make check       # синтаксис скриптов
make mars-check  # проверить зону БАНДИТ и библиотеку Pascal на 2348
make extract     # распаковать архив Ильина во временный каталог
make scan        # поиск маркеров в образах БЭСМ-6
```
