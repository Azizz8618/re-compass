# Checkpoint: восстановление СУБД КОМПАС для БЭСМ-6

Контрольная точка добавлена в репозиторий по указанию пользователя.

## Objective / Scope

- Основной текст КОМПАС сохранён на Pascal (PC-ветка Turbo Pascal 5/7 из архива Ильина).
- Нижний уровень работы с носителями заменён на систему МАРС-6: `src/comtup.pas`, 18 входов.
- Компас-БЭСМ работает под ДИСПАК/ДИАПАК с МС «Дубна» или Монитор-80; требует 240 восьм. зон дистрибутива и 63 зоны объектного кода. По указанию пользователя на диск пишется только объектный код.
- Рабочий диск 2348; зона `630₈` идентична зоне 630 диска 2048.
- SERVIS портирован на Паскаль-Монитор 15.1, подлинные деки Северова выполняются через front-end и порты компиляторных модулей.

## Done

- Базовый стек: `mars_smoke`, `kompas_suite` (10 проверок), `mars_check`.
- `src/comtup.pas`: op4 = `01c`, op89/op90 через op53 `243553c`/`352453c`, идемпотентный `SSBF5` (`BDVECT[36].i + 0 = 0`).
- Исправлена LU-рассогласованность КОБЛЫ: `2070000c` -> `20270000c`; runtime-диагностика МАРС устранена.
- Дефект ядра МАРС `BDBUF[DBLEN-1]` исправлен патчем на 4 слова без сдвига адресов (`tools/mars/apply_inplace_patch.py`): 1025+ зон дают ошибку `06`, регрессия пустая.
- Области `.ARE`: декодер, генераторы загрузки в МАРС; ZPROC 13/13, ADA 40/40, BPEMEH 25/25, SC 40/40 ключей.
- SERVIS: `src/servis.pas` (778 строк), 4 оператора K41 и gold-сокращения, затем 11 областей, дубли, журналы, ADMIN/ADA; подлинная дека создаёт 17 областей.
- Порты дек Северова: `src/servis_front.pas` (оригинальная дека как INPUT), `src/ttc15.pas`, `src/predtgen.pas`, `src/genmad.pas`.
- В `gold/output/` лежат 8 эталонных выводов по программам Северова.
- Все инструменты перенесены в `tools/mars/` и `tools/severov/`, описание в `tools/README.md`.
- Гипотеза «`ЗMП` = паспорт МС Дубна» опровергнута свипом 31 паспорта.
