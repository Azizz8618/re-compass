# Шапка задания и тестовые задания КОМПАС на simh

Проверено 24.11.2026: три колоды из этого документа прогнаны через `dispak`/simh.
Код завершения нулевой, поток ошибок пуст, диагностик нет, `КОНЕЦ ЗАДАЧИ`, `EXN=0`.

## 1. Обязательная подготовка

Перед любым заданием на 2348 должна быть собрана PERSO-библиотека `COMTUP` +
`SERVIS` в зоне 2570:

```sh
HOME=<каталог с пустым .besm6/input_queue> dispak --path=<disks> \
  -p tests/comtup_final_build.b6
```

Изолированный `HOME` обязателен: при заполненном общем `~/.besm6/input_queue`
`dispak` отвечает `БУФ ПЕРЕП` и не выдаёт результат в стандартный вывод (`docs/TSS-W5B.md`).

## 2. Шапка задания

```
шифр 419995зс5^
лен 40(2348-630)^
лен 41(2348)^
ОЗУ 32^
ее в1а3
*name 
*call yesmemory
*perso:412570
*stand
*call *pascal
```

Пояснения:

- `шифр 419995зс5^` - шифр задания;
- `лен 40(2348-630)^` и `лен 41(2348)^` - однодисковая схема 2348;
- `ОЗУ 32^` - память;
- `ее в1а3` - карта `EEB1A3`;
- `*name`, `*call yesmemory`, `*stand`, `*call *pascal` - стандартный мониторный каркас;
- `*perso:412570` - подключение готовой библиотеки `COMTUP`/`SERVIS`.

Далее следует исходник `src/servis.pas` (или `src/servis_front.pas` для подлинной
колоды), затем `*execute`, операторы SERVIS, `*end file`, ``````, `еконец`.

## 3. Тестовые задания

### 3.1 Создание БД (`tests/compass-jobs/job-create.b6`)

```
OБЛACTЬ TESTDB:ДЛИHA 8 PEЖИM 0,
OБЛACTЬ TESTJ:ДЛИHA 6 ВИД ЖYPHAЛ;
ПPOCTP TESTP:ДЛИHA 4;COЗДAT
B OБЛACTЬ TESTP.ПPOCTP,
КОНЕЦ.
```

Результат: `NЕW АRЕА N=1 INFО=2191425`, `N=2`, `N=3`, `ЕХN=0`.

### 3.2 Редактирование БД (`tests/compass-jobs/job-edit.b6`)

```
OБЛACTЬ TESTDB:ДЛИHA 8 PEЖИM 0;
ПPOCTP TESTP:ДЛИHA 4;COЗДAT
ИЗМЕНИТЬ ОБЛАСТЬ TESTDB: ДЛИНА 16,
ДУБЛЬ TESTD2 НА TESTDB,
ОБНОВИТЬ TESTP,
B OБЛACTЬ TESTP.ПPOCTP,
КОНЕЦ.
```

Результат: `ОБЛАСТЬ ТЕSТDВ ИЗМЕНЕНА`, `ДУБЛЬ ТЕSТD2 СОЗДАН`,
`ОБНОВЛЕНО ТЕSТР`, `ЕХN=0`.

### 3.3 Удаление БД (`tests/compass-jobs/job-drop.b6`)

```
OБЛACTЬ TESTDB:ДЛИHA 8 PEЖИM 0;
ПPOCTP TESTP:ДЛИHA 4;COЗДAT
OCBOБO TESTDB,
OЧИCTИ TESTDB,
УБРАТЬ ОБЛАСТЬ TESTDB,
B OБЛACTЬ TESTP.ПPOCTP,
КОНЕЦ.
```

Результат: `ТЕSТDВ ОСВОБОЖДЕНА`, `ТЕSТDВ ОЧИЩЕНА`,
`ОБЛАСТЬ ТЕSТDВ УБРАНА`, `ЕХN=0`.

## 4. Важные детали синтаксиса

- `ПPOCTP <имя>:ДЛИHA <n>;COЗДAT` создаёт область-пространство. Не объявляйте
  то же имя отдельной строкой `OБЛACTЬ`, иначе будет `ОШИБКА 80: ОБЪЕКТ УЖЕ ЕСТЬ`.
- `OЧИCTИ ZPROC` в этих заданиях не используется: в исходной деке он даёт
  ожидаемую `ОШИБКА 3: ОБЛАСТЬ НЕ ОПРЕДЕЛЕНА`, поскольку `ZPROC` не создаётся.
- Поддерживаются также `СОЗДАТЬ ПОЛЬЗОВАТЕЛЬ`, `СОЗДАТЬ ПРАВО`, `ЖYPHAЛ ...
  CБPOCИ/ЗАКРЕПИ`, `BOCCTA`, `OCBAБД` (полный список в `docs/SERVIS-STAGE4.md`).
- Эталоны: `tests/compass-jobs/job-*.expected.txt`.
