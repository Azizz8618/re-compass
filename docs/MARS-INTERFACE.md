# Интерфейс Pascal к системе МАРС

МАРС - архивная система В. И. Филиппова (ВЦ АН СССР). Ядро называется БАНДИТ и представляет собой интерпретатор микрокоманд в машинном коде БЭСМ-6. МАРС не написана на Pascal, но из Pascal к ней есть проверенный доступ, что и используется в этом проекте.

## Стандартные процедуры Паскаль-Монитора

Источник: `~/besm6.github.io/wiki/pascal-monitor.txt`, §Г4, строки 654-671.

| Процедура | Назначение | Микрокод из `sources/mars/README.md` |
|---|---|---|
| `NEWD` | отвести область МАРСа | 31-11-15-21-26-11-14-12-10-21 |
| `OPEND` | открыть область | 31-11-14-12-25 |
| `PUTD` | заслать значение Pascal-переменной в область | 11-15-21-26 |
| `GETD` | выбрать значение из области | 11-14-22 |
| `MODD` | модифицировать значение | 11-15-00-21-26-40-20 |
| `DELD` | исключить элемент | 11-14-23-27 |

Зоны по документации: система МАРС в 30-й восьм. зоне направления 40, область КОБЛА в 63-й восьм. зоне - общий каталог областей БД. Зона кодов системы КСМ переписывается отдельно от личной системной библиотеки компилятора (`pascal-monitor.txt:749-751`).

## Внешние процедуры

Источник: `~/besm6.github.io/sources/mars/pasbdi.asm`, `pasacd.asm`, `passetar.asm`, метка DTRAN 01.06.84.

| Процедура | Роль |
|---|---|
| `PASACD` | завести КОБЛУ (Fortran-вызываемая), например `PASACD(1520000B)` |
| `PASSETAR` | указать расположение КОБЛЫ в 4-й ячейке `P/BDSYS` |
| `PASBDI` | инициализация произвольных команд МАРС |
| `PASBD` | выполнение команды |
| `PASBDE` | обработчик ошибок по умолчанию, вызывается `*ERSTOP*` |
| `PAIB` | вспомогательная процедура интерфейса |

Общие листы: `*BDVECT*` (168 слов), `P/BDSYS`, `P/BDTAB`, `P/BDBUF`, `*BDC*`, `*BDERRN*`, `*ERSTOP*`. Код ошибки лежит в `*BDERRN*`; без инициализации `*BDVECT*` процедуры работают с мусорными указателями и падают «ЗАТЕРТО СПО» (`besm-crypto/work/README.md`).

`pasbdi.asm` содержит прямые константы микропрограмм, например `NEWD1 LOG 26 2115 1131`, `OPEND LOG 25 1214 1131`, `DELD LOG 2723 1411`, `PUTD LOG 2621 1511`, `GETD LOG 22 1411`, `MODD LOG 20 4026 2100 1511`.

## Рабочий пример

`~/besm6.github.io/sources/mars/sorucom.b6`, строки 69-87:

```pascal
i := 1270000c; PASACD(i);          { КОБЛА на LU 52 }
PASSETAR(270000c);
i := 1270001c;
newd('проба', i);
opend('проба');
s4 := 'он уважать себя заставил'; putd('iii. ', s4);
s5 := 'мой дядя самых честных правил '; putd('i. ', s5);
key := last;
while key <> zero do _( getd(key, s5); printn(key, s5); key := prev; _);
key := find('ii.   ');
```

`example.b6` добавляет `modd('val', a)` и `modd('val', a:1232b)`; `experiment.b6` задаёт `deld=27231411c` и показывает обращения через `bdvect[3]`, `[8]`, `[11]`, `[13]`, `[31]`.

## Что это значит для КОМПАС

17 внешних процедур `COMTUP.PAS` обращаются к резидентному ядру PC через `INT 12h`. На БЭСМ-6 их нужно реализовать заново поверх приведённых выше процедур МАРС, не меняя сигнатуры, чтобы верхние Pascal-слои (`TSSDML`, `UCOMPAS`, `TSERVIS`, `CMPSNO`) остались без изменений. Подробности: `PASCAL-SOURCES.md`.
