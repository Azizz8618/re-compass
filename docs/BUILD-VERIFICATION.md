## Ловушка с путём к диску

`besmtool` ищет образ через `BESM6_PATH`, а не в текущем каталоге. Проверка рабочей копии без `BESM6_PATH=.` читает `~/.besm6/2348` и показывает старый каталог. Правильный вызов:

```sh
cd <каталог с рабочей копией>
BESM6_PATH=. besmtool view 2348 --start=1400 --length=2 --encoding=t
```
