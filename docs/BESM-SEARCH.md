# Зоны и маркеры: результаты поиска

Первоначальный план поиска заменён конкретной картой зон после проверки дисков 2348 и 2048. Карта: `DISK-2348.md`.

## Подтверждённое

| Ориентир | Местоположение | Команда |
|---|---|---|
| ядро МАРС (БАНДИТ) | зона 0657 диска 2348 | `besmtool search 2348 БАНДИТ` |
| дамп ядра, 18 зон | md5 `1e0371b054f29adc7804d982bd8b3de6` | `besmtool dump 2348 --start=0657 --length=18 --to-file=...` |
| код МАРС для исторических колод | зона 630₈ тома 2048, `лен 40(2048-630)^` | `besmtool view 2048 --start=408 --length=2` |
| таблица ключевых слов Pascal с `NEWD`/`GETD`/`PUTD` | зоны 0312, 2061, 2062, 2604 | `besmtool view 2348 --start=312 --length=1 --encoding=t` |
| `PASBDI`, `PASBD`, `PASACD`, `PASSETAR`, `PASBDE` | зоны 1700, 1712, 2000, 2007 | `besmtool search 2348 PASBDI` |
| самодостаточная Pascal-библиотека | зона 2570₈ | `besmtool view 2348 --start=1400 --length=2 --encoding=t` |
| система МАРС по документации | 30-я восьм. зона направления 40 | `pascal-monitor.txt`, §Г4 |
| КОБЛА по документации | 63-я восьм. зона | `pascal-monitor.txt`, §Г4 |

## Отрицательные результаты

- `besmtool search 2348 MARS` не находит ничего: код помечен кириллицей `БАНДИТ`. Поиск вести по `БАНДИТ`, `КОБЛА`, `МАРС` в кодировках ГОСТ и CP866.
- Зоны 04030 и 04063 на образах 2048/2053/2148/2348 нулевые - готовой КОБЛЫ нет.
- `make scan` ищет маркеры КОБЛА, БАНДИТ, МАРС, ФИЛ, КОМПАС в UTF-8 и CP866 по всем образам; результат фиксируется в логе.

## Что делать с находкой

1. Зафиксировать образ, зону и смещение в логе.
2. Снять копию зоны в `build/`, эталон не изменять.
3. Дизассемблировать в `disasm/` с указанием инструмента и флагов.
4. Сверить с эталоном и записать результат в `verify/report.md`.
5. Обновить `STATUS.md` только после шага 4.

## Ограничения

- Дизассемблирование вести по одной зоне: лимит `disbesm6` - 32768 слов.
- Изменять образы 2348 и 2048 запрещено без отдельного разрешения и резервной копии.
- Полный md5 образа 2348 не инвариант, использовать контрольные суммы зон.
