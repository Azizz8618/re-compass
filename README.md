# re-compass: восстановление СУБД «КОМПАС» для БЭСМ-6

Репозиторий служит точкой сбора, проверки и публикации материалов по восстановлению сетевой СУБД «КОМПАС» (Компас-БЭСМ) для ЭВМ БЭСМ-6.

## Цель

Собрать подтверждённые сведения и артефакты, необходимые для восстановления Компас-БЭСМ, и довести работу до проверяемого результата: побайтовой сверки, эталонного вывода или документа-результата. Пока исходники и образы именно БЭСМ-версии не найдены, репозиторий честно фиксирует это и не выдаёт косвенные PC-материалы за восстановленный код.

## Что такое КОМПАС

«КОМПАС» - аббревиатура из штатной документации: «КОМПлекс Автоматизации Создания и Сопровождения информационных Систем». Это советский инструментальный комплекс с сетевой СУБД в ядре, созданный в ВЦ АН СССР с 1980 года, ведущий автор и руководитель В. И. Филиппов. Модель данных строится по рекомендациям комитета CODASYL (DDLC, 1978). Семейство включало Компас-БЭСМ, Компас-ЕС, Компас-СМ и Компас-РС (MS-DOS), совместимые на уровне интерфейсов.

## Подтверждённое о БЭСМ-версии

Из препринта 1990 года `PREPR90.ZIP/K1T1.TXT`, раздел 3 «Условия применения»:

> «Система Компас-БЭСМ может работать при любой конфигурации аппаратных средств, под ОС Диспак или Диапак, с использованием МС Дубна или Монитор-80.»

> «Для размещения дистрибутивной версии системы требуется 240 (восьм.) зон. Для размещения объектного кода системы - 63 (восьм.) зоны.»

Источник и точное расположение фрагмента приведены в `docs/KOMPAS-BESM.md`.

## Ключевое ограничение

Архив `Ильин_дискеты_февраль_2022.zip` содержит обширную документацию по КОМПАС и PC-дистрибутивы (Turbo Pascal, ассемблер, `.EXE`), но **не содержит исходников, листингов или зонных образов Компас-БЭСМ**. Все 62 образа `.IMA` внутри архива - обычные FAT-дискеты IBM PC. PC-материалы могут служить косвенным референсом архитектуры, но не восстановленным БЭСМ-кодом.

## Структура репозитория

| Каталог | Содержимое |
|---|---|
| `docs/` | план, статус, источники, пробелы, технические справки |

## Статус

Статус меняется только по факту, подтверждённым артефактом: логом побайтовой сверки, эталонным выводом или документом-результатом. Обозначения: `не начат` / `в работе` / `завершён` / `завершён с оговоркой` / `не требуется`. Текущее состояние: `docs/STATUS.md`.

## Использование

```sh
make help      # список целей
make extract   # распаковать архив Ильина во временный каталог
make scan      # поиск маркеров КОМПАС/МАРС в образах дисков БЭСМ-6
make check     # проверка синтаксиса скриптов
```

Пути к архиву и образам задаются переменными `ARCHIVE`, `SCRATCH`, `IMAGES`.
