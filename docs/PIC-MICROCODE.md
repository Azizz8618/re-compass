# Числовые константы Компас и микрокод PIC

Ключевой вывод: числа в вызовах `TPCMPP1`/`TPCMPIN1` из `UCOMPAS.PAS` **не являются кодами МАРС-6**. Это 16-битные слова микропрограммы PIC-машины Компас.

## Формат слова

`COMTUP.PAS` из `10_14/FILES/`, строки 358-361:

```pascal
W(low,high) := (word(high) shl 8) or low;
```

Младший байт слова - первый байт микрокода, старший байт - следующий. Например `7439 = 0x1D0F` - это `(15, 29)`, то есть операция 15 «замени» и операция 29 `ex` «выход в резидент`.

Назначение процедур из `MICROCOD.TXT` §2.1 (кодировка CP866):

| Процедура | Назначение |
|---|---|
| `TPCMPP1` | установка в `Pic.M` команд микрокода |
| `TPCMPL1` | установка в `Pic.L` литералов |
| `TPCMPIN1` | установка в `Pic.M` команд и вход в резидент |
| `TPCMPAD1` | установка в `Pic.L` адреса параметра процедуры |
| `SSBF5` | инициализация резидента |

## Декодированные операции

По `MICROCOD.TXT`, раздел 4.1.6 «ОПЕРАЦИИ РЕЗИДЕНТА» (номера **десятичные**): `01` поставить, `02` найти по ключу, `03` замени на, `04` найти первую, `05` найти владельца, `06` включить, `07` убрать, `08` исключить, `09` найти следующую в области, `10` найти по ключу без параметров, `11` найти последнюю, `12` найти следующую, `13` найти предыдущую, `15` замени, `16` взять, `17` спецвключение после исключения, `29` `ex`, `34` `utr`, `36` `varlo`, `39` `lotr`, `55` `ltrn`, `59` `zaver`, `66` `mgfal`, `67` `mgtrue`, `76` `mgel`, `77` `mgth`, `82` `kompas`, `89` и `90` - работа с бд-ключом записи.

`COpen` использует `34`, `5415`, `311`, `2599`, `823`/`55`, `2343`, `290`, `1063`, `1058`, `4647`: операции `utr`, `lotr` и `ltrn` задают поля PIC `SDL=21`, `SSD=10`, `SSPED=9`, `IPCX=4`, `AEXXN=18` и режим 0/1/3 (1 и 3 - «только чтение»). Подтверждено `COMTUP.PAS:377-387` и `TSPIC.PAS:37-82`.

`TPCMPL1` (2466, 2195, 21331, 8224) загружает литералы Pic.L: имя, адреса, `SS`. Это не операторы.

## Важное предупреждение

В `MICROCOD.TXT` номера операций **десятичные**, в `sources/mars/README.md` коды МАРС **восьмеричные**. Совпадение начертаний (`36`, `29`, `34`) не означает совпадения операций. Например `36₁₀ = 44₈`, а PIC-op36 `varlo` не равен МАРС-op44 «add a key»; `55₁₀ = 67₈` вообще вне диапазона МАРС 00-55₈. Числа из `UCOMPAS.PAS` нельзя «перевести» в коды МАРС по значению.

## Следствие для порта

Правильный путь - заменить реализацию всех 17 внешних процедур `COMTUP`, сохранив их сигнатуры. Верхние слои (`UCOMPAS`, `TSSDML`, `CMPSNO`) остаются без изменений, но генерация PIC-микрокода исчезает вместе со старым `COMTUP`.

Семантический мостик (гипотеза, требует проверки на эмуляторе):

| Процедура КОМПАС | Операция МАРС |
|---|---|
| `CGetKnot` | `GETD 11-14-22` |
| `CPlace` | `PUTD 11-15-21-26` |
| `CReplace`, `CReplaceElement` | `MODD 11-15-00-21-26-40-20` |
| `CRemove`, `CExclude` | `DELD 11-14-23-27` |
| `COpen` | `OPEND 31-11-14-12-25` или `NEWD` |
| `CClose` | сброс буферов и stop |
| итераторы `CFindFirst`/`Next`/`Preceding`/`End` | операции МАРС 01-04 и 11 |

Точное соответствие для `CGetBdKey`, `CPutBdKey`, `CFindByKeyElement` (операции над `BDVECT`, МАРС 50-54) - `НЕ ИЗВЕСТНО`.

Особого внимания требуют `SSBF5` (инициализация, аналог `VTM/UTC` в `PASBDI`), `TPCMPAD1` (адреса Pascal-переменных, нужен явный дескриптор `BDVECT`), `EXN`/`CmpsOk` (код `*BDERRN*`), `APIC`/`ITLEN` (доступ к PIC и длинам).
