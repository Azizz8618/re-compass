# Промежуточный отчёт

Состояние на 23.11.2026. Отчёт обновляется по мере появления проверяемых артефактов.

## Главный вывод

Основной текст КОМПАС сохранился на Pascal (PC-ветка Turbo Pascal 5/7 из архива Ильина). Нижний уровень работы с носителями в PC-версии - `COMTUP.PAS` и `COMPASST.OBJ` - подлежит замене на вызовы системы МАРС, которая доступна на БЭСМ-6 и вызывается из Pascal. Рабочий диск - 2348. Задача сводится к порту нижнего уровня, а не к написанию системы с нуля.

## Что сделано

- Клонирован пустой репозиторий `re-compass`, создана структура проекта, сделан начальный коммит.
- Инвентаризирован архив Ильина: 804 файла, 207 каталогов. Вложенные архивы вскрыты рекурсивно.
- Найдены и прочитаны Pascal-исходники: `TSSDML.PAS` (3142 строки), `COMFY.PAS`, `TTC.PAS`, `UCOMPIL.PAS`, `UCOMPAS.PAS`, `CMPSNO.PAS`, `TSPIC.PAS`, `COMTUP.PAS`. Составлен список «брать как есть / портировать / заменять»: `PASCAL-SOURCES.md`.
- Подтверждено прямое указание на ДИСПАК/ДИАПАК и требования 240/63 восьм. зон (`K1T1.TXT`).
- Подтверждено наличие ядра БАНДИТ на диске 2348 в зоне 0657 и интерфейсных модулей `PASBDI`/`PASACD` в зонах 1700/1712/2000/2007. Контрольная сумма дампа зоны 0657 одинакова для обеих копий образа.
- Собраны правила работы с 2348 из смежных проектов: `RULES-2348.md`.

## Что не найдено

- Исходников Компас-БЭСМ как таковых: в архиве только PC-ветка и документация.
- Полного текста доклада 1983 года и оцифрованных руководств 1981/1987/1990/1991.
- Готовой КОБЛЫ на образах дисков: она создаётся во время прогона.

## Что проверяется далее

1. Дымовой тест МАРС из Pascal по `sorucom.b6`.
2. Таблица соответствия 16 процедур `COMTUP` операциям МАРС.
3. Сопоставление кодов `UCOMPAS.PAS` с `MICROCOD.TXT`.
4. Контрольный пример на 2348 с побайтовой сверкой.

## Честные «НЕ ИЗВЕСТНО»

- Насколько PC-ветка повторяет алгоритмы БЭСМ-версии.
- Как именно отображаются числовые коды PC-ядра на операции МАРС.
- Полная семантика микрокоманд МАРС (понятна меньше половины из 46).
- Статус авторских прав на архивные тексты.
