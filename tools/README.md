# Инструменты восстановления

Все скрипты работают только с **рабочими копиями** дисков. Оригинальные образы в `~/.besm6` и `/usr/local/share/besm6` менять запрещено правилами проекта (`docs/RULES-2348.md`).

## Корень `tools/`

| Скрипт | Назначение |
|---|---|
| `extract_ilyin.sh` | распаковка архива Ильина с вложенными архивами |
| `find_besm_artifacts.sh` | поиск маркеров КОМПАС/МАРС в образах БЭСМ-6 |
| `mars_check.sh` | проверка зоны БАНДИТ 0657 и библиотеки `PASBDI` |
| `run_smoke.sh` | воспроизведение `tests/mars_smoke.b6` |
| `run_kompas_suite.sh` | сборка COMTUP и прогон `tests/kompas_suite.b6` |
| `are_decode.py` | декодер страниц областей `.ARE` в JSON (`docs/ARE-DATA.md`) |
| `are_to_mars.py` | генератор деки загрузки одностраничной области в МАРС |
| `are_to_mars_multi.py` | то же для многостраничных областей, с разбиением на процедуры |

## `tools/mars/` - пересборка ядра

Инструмент - встроенный в `dispak` макро-БЕМШ-транслятор (макроредактор 20.06.78). Контрольный опыт: 873 слова `re-mars.asm` побайтово совпадают с дампом зоны 0657.

| Файл | Назначение |
|---|---|
| `re-mars.asm` | дизассемблированный исходник ядра из `besm6.github.io/sources/mars/` |
| `re-mars-fixed.asm` | тот же исходник с тремя константами, заменёнными на литералы (`В'22'`, `В'14'`, `В'4'`) для чистой трансляции |
| `compile_mars_macro.sh` | контрольная компиляция неизменённого исходника в листинг |
| `compile_fixed.sh` | компиляция `re-mars-fixed.asm` |
| `compile_to_zone.sh` | запись скомпилированных слов в зону рабочей копии 2348 |
| `parse_words.py` | разбор листинга в 48-битные слова БЭСМ-6 |
| `re-mars-limit-1024.patch` | патч дефекта `BDBUF[DBLEN-1]`: при `DBLEN > E11` переход на диагностику `06 ПЕРЕПОЛНЕНА` |
| `DEFECT.md` | описание дефекта и обоснование патча |
| `patch_workdisk.sh` | применяет in-place патч зоны 0657 к рабочей копии 2348; проверяет md5 pristine-дампа (`1e0371…`), пропатченной зоны (`6be325…`) и 18-зонного дампа (`b0b34e…`); для `besmtool` явно выставляет `BESM6_PATH=<каталог образов>` |

Вызов: `bash tools/mars/patch_workdisk.sh <каталог-с-рабочей-копией-2348> [pristine-dump]`.
Второй аргумент необязателен: без него эталонный дамп зоны 0657 снимается с
той же рабочей копии. Перед вызовом 2348 нужно восстановить из резерва, иначе
повторное наложение патча не пройдёт проверку эталонной контрольной суммы.
| `apply_inplace_patch.py`, `inplace-patch.asm` | рабочий патч на 4 слова в зоне 0657 без сдвига адресов: `apply_inplace_patch.py <pristine-dump> <output-dump>`, затем записать дамп в рабочую копию 2348 |

Порядок: скопировать образы в `tools/mars/images/`, задать `BESM6_PATH` на эту копию, запустить `compile_fixed.sh`, затем `parse_words.py` и `compile_to_zone.sh`. `ПЕЧМАК` в задании обязателен: без него листинг не печатает слова, сгенерированные макросами.

## `tools/severov/` - материалы и порты деков

| Файл | Назначение |
|---|---|
| `mkfront.py` | собирает `src/servis_front.pas` и `tests/original_deck_front*.b6`: подлинные 41 строка деки подаются как `INPUT`, системные карты пропускаются |
| `extract_gold.py` | вырезает строки дек 6/7/11 и MAD-деков 3/8/9 из `gold/` в cards-файлы |
| `genmad_make_deck.py` | генератор деки для `src/genmad.pas` |
| `ttc_make_deck.py` | генератор деки для `src/ttc15.pas` |
| `predt_run.sh` | воспроизведение `tests/predtgen.b6` |
| `chunk_*.py`, `chunk_*.sh` | генераторы и runners реестра кусков для логической области 1750 зон |

Генераторы `chunk_*` создавались для scratch-экспериментов и могут содержать локальные пути; перед использованием их нужно адаптировать под конкретный scratch-каталог.

## Эталонные выводы

Корректные outputs по программам Северова лежат в `gold/output/` с описанием соответствия декам в `gold/output/README.md`.
