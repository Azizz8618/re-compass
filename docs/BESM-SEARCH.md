# Поиск БЭСМ-6 артефактов

Цель: найти в образах дисков следы Компас-БЭСМ, МАРС-6 и связанных структур данных.

## Известные ориентиры

| Ориентир | Местоположение | Источник |
|---|---|---|
| система МАРС | 30-я восьм. зона направления 40 | `pascal-monitor.txt`, §Г4 |
| область КОБЛА, общий каталог областей БД | 63-я восьм. зона | `pascal-monitor.txt`, §Г4 |
| КОБЛА | зона 10268 образа `2048` | `besm6.github.io` |
| БАНДИТ, «БАНк Данных И Текстов» | зона 10278 образа `2048` | сообщение Филиппова Брухису |
| дистрибутив Компас-БЭСМ | 240 восьм. зон | `K1T1.TXT`, разд. 3 |
| объектный код Компас-БЭСМ | 63 восьм. зоны | `K1T1.TXT`, разд. 3 |

## Маркеры для поиска

`КОБЛА`, `БАНДИТ`, `МАРС`, `ФИЛ`, `КОМПАС`, `Компас`, `SYSTEM`, `ЯОД`, `ЯМД`.

Тексты на БЭСМ-6 встречаются в кодировке CP866 и в других вариантах, поэтому поиск ведётся сразу в UTF-8 и CP866, по байтовым последовательностям, без привязки к текстовым строкам.

## Образы для проверки

```
/usr/local/share/besm6/2048
/usr/local/share/besm6/2053
/usr/local/share/besm6/2113
/usr/local/share/besm6/2248
/usr/local/share/besm6/2348
```

## Команды

```sh
# быстрый поиск маркеров во всех образах
make scan

# поиск по конкретным образам
bash tools/find_besm_artifacts.sh /usr/local/share/besm6/2048 /usr/local/share/besm6/2053

# дизассемблирование зоны (инструменты из смежных проектов)
disbesm6 /usr/local/share/besm6/2048 10268
dtran /usr/local/share/besm6/2048 --zone=10278
```

## Что делать с находкой

1. Зафиксировать смещение, зону и образ в логе.
2. Снять копию зоны в `build/`, эталон не изменять.
3. Дизассемблировать в `disasm/` с указанием инструмента и версии.
4. Сверить с эталонной зоной и записать результат в `tests/`.
5. Обновить `STATUS.md` только после шага 4.

## Ожидаемые трудности

- Образы могут содержать только остатки структур, а не полный дистрибутив на 240 зон.
- Маркеры КОМПАС в образах могут отсутствовать, если система хранилась под другим именем.
- Часть зон может быть занята архивной системой МАРС без прямого указания «Компас».
