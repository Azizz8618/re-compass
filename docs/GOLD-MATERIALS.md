### Ценность для реставрации

- **Независимый источник 1988-89 годов**: не спецификация и не низкоуровневый тест, а работающая прикладная система - схема, загрузка, MAD, интерактивные Pascal-программы с ЯМД-вставками.
- **Таблица кодов ЯМД 01-17** (строки 158-166, 308-316, 868-876) совпадает с `MICROCOD.TXT` §4.1.6: `01 ПOCTAB`, `04 HAЙTИ ПEPBYЮ`, `05 HAЙTИ BЛAДEЛ`, `06 BKЛЮЧИ`, `07 YБPATЬ`, `08 ИCKЛЮЧИ`, `10 HAЙTИ ПO-KЛЮ`, `11 HAЙTИ ПOCЛEД`, `12 HAЙTИ CЛEДYЮ`, `13 HAЙTИ ПPEДЫД`, `14 BЗЯTЬ HA`, `15 ЗAMEHИ`, `16 BЗЯTЬ`. Это подтверждает, что десятичные коды - общее наследие семейства, а не изобретение PC-версии.
- **Прямые примеры бд-ключа**: `VAR KEYBD:ZZBDKEY` (3289), `&&BЗЯTЬ БД-KЛЮ OTДEЛ HA KEYBD;BЗЯTЬ&&` (3298), `&&ЗAMEHИ БД-KЛЮ OTДEЛ HA KEYBD;` (3299), плюс рекурсивный обход с `TEKЗAП:ZZBDKEY` (4161, 4171-4172). Это семантический эталон для наших op89/op90.
- **Итераторы**: `HAЙTИ ПEPBYЮ/СЛEДYЮ/ПPEДЫД/ПOCЛEД` дают acceptance-тесты для `cFirst/cNext/cPrev/cLast`.
- **Жизненный цикл сессии**: `ЖYPHAЛ ЖY-CK0 CБPOCИ.` (458), `&&ЖYPHAЛ ЖY-CK0;KOMПAC&&` (1122), `&&ЗABEPШ&&` (1338).

Гипотеза: именно этот слой может служить промежуточным эталоном, подтверждающим мост Компас-БЭСМ - PIC - МАРС. Прямого доказательства, что PC-текст писался под порт на БЭСМ, файл не содержит.

## 3. Запуск на эмуляторе

Подробный протокол: `GOLD-RUN-REPORT.md`.

- Транслитерацию исправлять не нужно: `dispak/dispak/encoding.c` отображает латинские гомоглифы в тот же код ГОСТ 10859. BOM допустим, а **CRLF недопустим**: колода с CRLF даёт `exit=134`, `НЕТ КОНЦА ВВОДА`, stack smashing. Рецепт: `utf-8-sig`, запись с `newline='\n'`.
- **Подлинная КОМПАС-колода не запускается**: паспорт `ЗMП` отсутствует в таблице СТПАСП на 2053/0543; том `1C` с компилятором КОМПАС недоступен. После подмены паспорта на `зс5` монитор печатает `ILLЕGАL SУSТЕМ САRD` для `*CMP`/`*SERVIS`.
- **Рабочий контрольный пример**: подлинный текст `SHTAMP` из `raznoe.txt:52-116` с добавленной главной программой и заглушками `GRID`/`MOVE` (графическая библиотека на LU 67 отсутствует). `tests/gold_shtamp.b6` / `tests/gold_shtamp_v.b6`, exit 0, `stderr=0`.
- Проверка: Python пересчитал координаты по константам `A(nn)` из исходника - 44 точки для `NS=0`, 58 точек для `NS=1`, `match: True`. Программа `SHTAMP` строит контур штампа; `L=0` - горизонтальная укладка, `L>0` - вертикальная с инверсией Y.

Оценка: материал пригоден как регрессионный тест кодировки, формата колоды и Дубнинского ФОРТРАН-компилятора, но **не является тестом КОМПАС**. Для запуска `*CMP`/`*SERVIS` нужно восстановить таблицу паспортов на 2053 и получить системный том `1C`.
